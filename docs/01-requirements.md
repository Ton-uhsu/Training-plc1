# Requirements: Smart Farm Hydroponic PLC Simulator

## สถานะเอกสาร

- สถานะ: Confirmed draft
- วันที่: 2026-09-18
- วัตถุประสงค์: ใช้เป็นต้นแบบสำหรับฝึกเขียนโปรแกรม PLC
- ขอบเขต: จำลองระบบ Smart Farm Hydroponic โดยไม่มีการปลูกพืชและไม่ใช้น้ำจริง

## 1. ภาพรวมระบบ

ต้นแบบนี้ใช้สำหรับฝึกการรับสัญญาณ Input การสั่งงาน Output การอ่าน Sensor ผ่าน RS-485 Modbus RTU การเขียนลำดับการทำงาน และการจัดการ Alarm ของ PLC

อุปกรณ์ภาคสนามไม่จำเป็นต้องเป็นปั๊ม วาล์ว หรือ Sensor จริงทั้งหมด โดยสามารถใช้:

- สวิตช์แทน Sensor ระดับน้ำและ Flow Switch
- Modbus Simulator แทน EC, pH และ Temperature/Humidity Sensor
- หลอดไฟ 24 VDC แทนปั๊ม วาล์ว พัดลม และมอเตอร์

ระบบไม่มี HMI ในขอบเขตปัจจุบัน

## 2. กระบวนการที่ต้องจำลอง

ระบบต้องจำลองกระบวนการหลักดังนี้:

1. ตรวจระดับและเติมน้ำในถัง
2. หมุนเวียนน้ำผ่านระบบปลูก
3. ตรวจและควบคุมอุณหภูมิกับความชื้นในโรงเรือน
4. ผสมปุ๋ยตามค่า EC
5. ปรับค่า pH
6. ควบคุมการเริ่ม หยุด และหยุดฉุกเฉิน
7. ตรวจความผิดปกติและแจ้ง Alarm

## 3. รายการอุปกรณ์

### 3.1 อุปกรณ์ควบคุมหลัก

| อุปกรณ์ | จำนวน | หน้าที่ |
| --- | ---: | --- |
| PLC | 1 | ประมวลผลและควบคุมระบบทั้งหมด |
| พอร์ตหรือโมดูล RS-485 | 1 | สื่อสารกับ Sensor ด้วย Modbus RTU |
| Power Supply 24 VDC | 1 | จ่ายไฟให้ PLC และอุปกรณ์จำลอง |
| Relay Interface | ตามจำนวนโหลด | แยกวงจร Output ของ PLC ออกจากโหลด |
| เบรกเกอร์หรือฟิวส์ | ตามความเหมาะสม | ป้องกันวงจรไฟฟ้า |
| Terminal Block และสายไฟ | ตามความเหมาะสม | ใช้ต่อวงจรบนแผงทดลอง |
| แผงหรือตู้สาธิต | 1 | ติดตั้งอุปกรณ์และใช้ฝึกต่อสาย |

### 3.2 Digital Input

| สัญญาณ | จำนวน | หน้าที่ |
| --- | ---: | --- |
| Float Switch Low | 1 | แจ้งว่าระดับน้ำต่ำ |
| Float Switch High | 1 | แจ้งว่าน้ำถึงระดับเต็ม |
| Flow Switch | 1 | ยืนยันว่ามีน้ำไหลหลังเปิดปั๊มหมุนเวียน |
| Emergency Stop แบบ NC | 1 | หยุดระบบฉุกเฉิน |
| ปุ่ม START | 1 | เริ่มระบบ |
| ปุ่ม STOP | 1 | หยุดระบบปกติ |
| ปุ่ม RESET ALARM | 1 | ล้าง Alarm หลังแก้สาเหตุแล้ว |
| Selector Switch MANUAL/AUTO | 1 | เลือกโหมดการทำงาน |

จำนวนเริ่มต้นประมาณ 8 Digital Inputs ทั้งนี้จำนวนจริงขึ้นกับชนิดหน้าสัมผัสของ Selector Switch และรูปแบบการต่อวงจร

### 3.3 Sensor แบบ RS-485 Modbus RTU

| Sensor | จำนวน | ค่าที่อ่าน |
| --- | ---: | --- |
| EC Sensor RS-485 | 1 | ความเข้มข้นของสารอาหาร |
| pH Sensor RS-485 | 1 | ความเป็นกรดและด่าง |
| Temperature/Humidity Sensor RS-485 | 1 | อุณหภูมิและความชื้นในโรงเรือน |

Modbus Address เริ่มต้นที่เสนอ:

| อุปกรณ์ | Address |
| --- | ---: |
| Temperature/Humidity Sensor | 1 |
| EC Sensor | 2 |
| pH Sensor | 3 |

Address, Baud Rate, Parity และ Register Map ต้องปรับตามคู่มือ Sensor หรือโปรแกรม Simulator ที่เลือกใช้จริง

### 3.4 Digital Output

| สัญญาณ | จำนวน | หน้าที่ |
| --- | ---: | --- |
| Solenoid Valve เติมน้ำ | 1 | เติมน้ำเข้าสู่ถัง |
| ปั๊มน้ำหมุนเวียน | 1 | หมุนเวียนน้ำผ่านระบบปลูก |
| พัดลมระบายอากาศ | 1 | ลดอุณหภูมิหรือความชื้น |
| ระบบพ่นหมอก | 1 | ลดอุณหภูมิเมื่อความชื้นไม่สูงเกินไป |
| ปั๊มปุ๋ย A | 1 | จ่ายปุ๋ยส่วน A |
| ปั๊มปุ๋ย B | 1 | จ่ายปุ๋ยส่วน B |
| ปั๊ม pH Up | 1 | เพิ่มค่า pH |
| ปั๊ม pH Down | 1 | ลดค่า pH |
| มอเตอร์กวน | 1 | ผสมน้ำ ปุ๋ย และสารปรับ pH |
| ไฟ RUN | 1 | แสดงว่าระบบกำลังทำงาน |
| ไฟ ALARM | 1 | แสดงว่าระบบมีความผิดปกติ |
| Buzzer | 1 | แจ้งเตือนด้วยเสียง |

จำนวนเริ่มต้นประมาณ 12 Digital Outputs ในชุดจำลองสามารถใช้หลอดไฟ 24 VDC แทนอุปกรณ์ขับเคลื่อนแต่ละตัว

## 4. Functional Requirements

### REQ-001: การเริ่มและหยุดระบบ

- เมื่อจ่ายไฟ ระบบต้องอยู่ในสถานะหยุดรอ
- เมื่อกด START และไม่มี Alarm ระบบจึงเริ่มทำงานได้
- เมื่อกด STOP ระบบต้องหยุดการทำงานปกติ
- ไฟ RUN ต้องติดเมื่อระบบอยู่ในสถานะทำงาน
- เมื่อเกิดความผิดปกติ ไฟ ALARM และ Buzzer ต้องทำงาน
- หลังแก้สาเหตุแล้ว ผู้ใช้ต้องกด RESET ALARM ก่อนเริ่มระบบใหม่

### REQ-002: Emergency Stop

- Emergency Stop ต้องมีลำดับความสำคัญสูงสุด
- เมื่อกด Emergency Stop ระบบต้องปิดปั๊ม วาล์ว ระบบพ่นหมอก และมอเตอร์กวนทั้งหมด
- ระบบต้องเปิดไฟ ALARM
- ระบบต้องไม่เริ่มใหม่เองเมื่อปล่อย Emergency Stop
- ผู้ใช้ต้องกด RESET ALARM และกด START ใหม่

> หมายเหตุด้านความปลอดภัย: หากนำไปต่อโหลดจริง ควรตัดกำลังด้วย Safety Relay หรือวงจร Hardwired Safety ไม่ควรพึ่งโปรแกรม PLC เพียงอย่างเดียว

### REQ-003: การตรวจและเติมน้ำ

- ระบบต้องตรวจระดับน้ำด้วย Float Switch ระดับ LOW และ HIGH
- เมื่อน้ำต่ำกว่า LOW ระบบต้องหยุดปั๊มหมุนเวียนและเปิดวาล์วเติมน้ำ
- วาล์วเติมน้ำต้องทำงานต่อจนระดับน้ำถึง HIGH
- เมื่อถึง HIGH ระบบต้องปิดวาล์วเติมน้ำ
- ระหว่างน้ำต่ำ ระบบต้องห้ามการผสมปุ๋ยและการปรับ pH
- หากเติมน้ำนานเกินเวลาสูงสุดแล้วยังไม่ถึง HIGH ระบบต้องปิดวาล์วและแจ้ง Alarm

### REQ-004: การหมุนเวียนน้ำ

- ในโหมด AUTO ปั๊มหมุนเวียนต้องทำงานตามรอบเวลาที่กำหนด
- หลังสั่งปั๊ม PLC ต้องรอสัญญาณยืนยันจาก Flow Switch
- หากไม่มี Flow ภายในเวลาที่กำหนด ระบบต้องหยุดปั๊มและแจ้ง Alarm
- หากน้ำต่ำกว่า LOW ระบบต้องหยุดปั๊มทันทีเพื่อป้องกันปั๊มแห้ง
- ในโหมด MANUAL ปุ่ม START และ STOP ใช้ทดสอบปั๊มหมุนเวียน
- ระบบจ่ายปุ๋ยและปรับ pH ต้องไม่ทำงานในโหมด MANUAL

### REQ-005: การควบคุมอุณหภูมิและความชื้น

- PLC ต้องอ่านอุณหภูมิและความชื้นผ่าน RS-485 Modbus RTU
- เมื่ออุณหภูมิสูง ระบบต้องเปิดพัดลมระบายอากาศ
- เมื่อความชื้นสูง ระบบต้องเปิดพัดลมระบายอากาศ
- เมื่ออุณหภูมิสูงและความชื้นยังไม่สูงเกิน ระบบจึงเปิดระบบพ่นหมอกได้
- เมื่อความชื้นสูงเกิน ระบบต้องห้ามการพ่นหมอก
- ระบบต้องใช้ค่าเปิดและค่าปิดคนละค่า หรือ Hysteresis เพื่อป้องกันอุปกรณ์ตัดต่อถี่

ค่าตั้งต้นสำหรับทดลอง ซึ่งยังปรับได้ภายหลัง:

- พัดลมเปิดเมื่ออุณหภูมิสูงกว่า 30 °C
- พัดลมปิดเมื่ออุณหภูมิต่ำกว่า 28 °C
- พ่นหมอกเมื่ออุณหภูมิสูงกว่า 32 °C
- ห้ามพ่นหมอกเมื่อความชื้นสูงกว่า 85 %RH

### REQ-006: การผสมปุ๋ยตามค่า EC

- ระบบผสมปุ๋ยทำงานได้เมื่อระดับน้ำเพียงพอ ไม่มี Emergency Sensor EC สื่อสารได้ และระบบอยู่ในโหมด AUTO
- หาก EC ต่ำกว่าค่าที่ตั้ง ระบบต้องเปิดมอเตอร์กวน
- ระบบต้องจ่ายปุ๋ย A และ B ทีละตัวตามเวลาที่กำหนด
- ปั๊มปุ๋ย A และ B ต้องไม่ทำงานพร้อมกัน
- หลังจ่ายปุ๋ย ระบบต้องกวนและรอให้สารผสมก่อนอ่านค่า EC ใหม่
- หาก EC ยังต่ำ ระบบสามารถทำซ้ำได้
- เมื่อ EC ถึงค่าที่กำหนด ระบบต้องหยุดจ่ายปุ๋ย
- ต้องจำกัดจำนวนรอบหรือเวลาจ่ายสูงสุด เพื่อป้องกันการจ่ายไม่หยุดเมื่อ Sensor ผิดปกติ

### REQ-007: การปรับค่า pH

- PLC ต้องอ่านค่า pH ผ่าน RS-485 Modbus RTU
- เมื่อ pH ต่ำกว่าค่าที่ตั้ง ระบบต้องจ่าย pH Up
- เมื่อ pH สูงกว่าค่าที่ตั้ง ระบบต้องจ่าย pH Down
- ปั๊ม pH Up และ pH Down ต้องไม่ทำงานพร้อมกัน
- ระบบต้องจ่ายสารเป็นช่วงเวลาสั้น ๆ แล้วกวนและรอก่อนอ่านค่าใหม่
- ต้องกำหนดเวลาจ่ายสูงสุดและแจ้ง Alarm เมื่อไม่สามารถปรับค่าเข้าสู่ช่วงที่กำหนดได้

### REQ-008: การตรวจสอบการสื่อสาร Sensor

- PLC ต้องตรวจว่าการสื่อสารกับ Sensor RS-485 แต่ละตัวเป็นปกติ
- หาก EC Sensor ขาดการสื่อสาร ระบบต้องห้ามจ่ายปุ๋ย
- หาก pH Sensor ขาดการสื่อสาร ระบบต้องห้ามจ่าย pH Up และ pH Down
- หาก Temperature/Humidity Sensor ขาดการสื่อสาร ระบบต้องปิดระบบพ่นหมอก
- ระบบสามารถเปิดพัดลมในสถานะปลอดภัยเมื่อ Temperature/Humidity Sensor ขาดการสื่อสาร
- ทุกกรณีต้องแจ้ง Communication Alarm

### REQ-009: การจำลองอุปกรณ์

- Digital Input จาก Float Switch และ Flow Switch สามารถใช้ Toggle Switch จำลองได้
- Sensor RS-485 สามารถใช้ Modbus Simulator จำลองค่าได้
- Digital Output สำหรับปั๊ม วาล์ว พัดลม และมอเตอร์สามารถใช้หลอดไฟแสดงสถานะแทนได้
- ผู้ฝึกต้องสามารถเปลี่ยนค่า Sensor และสถานะ Input เพื่อทดสอบ Normal, Warning, Alarm และ Emergency ได้

## 5. Flow การทำงานแบบภาษาคน

1. เมื่อเปิดระบบ PLC ตรวจ Emergency Stop และตรวจว่า Sensor RS-485 ติดต่อได้หรือไม่
2. PLC รอจนผู้ใช้กด START
3. PLC ตรวจระดับน้ำ หากน้ำต่ำจะหยุดปั๊มและเปิดวาล์วเติมน้ำจนถึงระดับ HIGH
4. เมื่อน้ำเพียงพอ PLC เปิดปั๊มหมุนเวียนตามรอบเวลาที่ตั้งไว้
5. หลังเปิดปั๊ม PLC ตรวจ Flow Switch หากไม่มีน้ำไหลภายในเวลาที่กำหนดจะหยุดปั๊มและแจ้ง Alarm
6. PLC อ่านอุณหภูมิและความชื้น หากร้อนหรือชื้นเกินจะเปิดพัดลม
7. หากอากาศร้อนแต่ความชื้นยังไม่สูงเกิน PLC จึงเปิดระบบพ่นหมอก
8. PLC อ่านค่า EC หากต่ำกว่าค่าที่ตั้งจะจ่ายปุ๋ย A และ B ตามลำดับ เปิดมอเตอร์กวน แล้วรอก่อนวัดซ้ำ
9. PLC อ่านค่า pH หากต่ำจะจ่าย pH Up หากสูงจะจ่าย pH Down จากนั้นกวนและรอก่อนวัดซ้ำ
10. PLC วนตรวจทุกส่วนซ้ำตลอดเวลาที่ระบบทำงาน
11. หากกด STOP ระบบจะหยุดตามปกติ หากกด Emergency Stop ระบบจะหยุด Output ทั้งหมดทันทีและรอการ Reset

## 6. ลำดับความสำคัญของคำสั่ง

จากสำคัญมากไปน้อย:

1. Emergency Stop
2. STOP และสถานะ Alarm ที่ต้องหยุดระบบ
3. ป้องกันระดับน้ำต่ำและปั๊มแห้ง
4. ป้องกันการจ่ายปุ๋ยหรือสารปรับ pH เกิน
5. ควบคุมอุณหภูมิและความชื้น
6. การทำงานอัตโนมัติตามปกติ

คำสั่งที่มีลำดับสูงกว่าต้องสามารถยกเลิกคำสั่งที่มีลำดับต่ำกว่าได้เสมอ

## 7. ประเด็นที่ต้องกำหนดก่อนเขียน Ladder ฉบับสมบูรณ์

- รุ่น PLC และจำนวน I/O ที่มีจริง
- Modbus Register Map ของ Sensor หรือ Simulator
- ค่า EC เป้าหมายและช่วง Hysteresis
- ค่า pH เป้าหมายและช่วง Hysteresis
- รอบเวลาเปิดและปิดปั๊มหมุนเวียน
- เวลาจ่ายปุ๋ย A/B ต่อหนึ่งรอบ
- เวลาจ่าย pH Up/Down ต่อหนึ่งรอบ
- เวลากวนและเวลารอก่อนอ่าน Sensor ซ้ำ
- Timeout ของการเติมน้ำและ Flow Switch
- เงื่อนไขว่า Alarm แต่ละชนิดต้องหยุดทั้งระบบหรือหยุดเฉพาะส่วนที่เกี่ยวข้อง
